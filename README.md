# CodeMint

CodeMint is an in-browser code editor with instant execution, test-case validation, and AI-powered code suggestions to help you write cleaner code, faster.

## Features
- Monaco-based editor with JS + Python support
- GitHub Light/Dark theme toggle
- Run code and see real output (Piston-powered)
- Custom test cases with pass/fail results
- AI + linter-powered code suggestions

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Monaco Editor
- **Backend:** Node.js, Express
- **Execution:** Piston (self-hosted, Docker)
- **Static Analysis:** ESLint / Pylint
- **AI Feedback:** Claude API
- **Database:** MongoDB Atlas
- **Auth:** JWT + Google OAuth
- **Charts:** Recharts

## Getting Started

```bash
git clone https://github.com/<your-username>/codemint.git
cd codemint
npm install
npm run dev
```
